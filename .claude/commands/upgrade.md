# /upgrade — Safe Agent Harness Upgrade

Use this command to improve the agent system itself: prompts, command adapters, routing rules, memory schemas, validation gates, installer templates, or tool-use workflows.

Read `agent-memory/active.md`, `agent-memory/index.md`, `agent-memory/candidates.md`, `agent-memory/metrics.md`, `agent-memory/harness-proposals.md`, and `agent-memory/harness-regression-tests.md`.

Mine recurring weaknesses, propose the smallest harness change, validate it, apply only safe Markdown harness changes, and report weakness/proposal/validation/changes/risk/next check.

Do not change product code unless explicitly requested.
